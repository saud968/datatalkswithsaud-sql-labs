# Contributing

We welcome corrections, accessible explanations, additional reproducible SQL exercises and synthetic datasets.

- Keep educational files fictional; never include confidential employer/client data, customer identifiers, credentials, or unauthorized paid course material.
- Run `python scripts/run_all.py` locally; new exercises need a matching expected result, and the supplied solutions must pass.
- Explain the SQL dialect used and give evidence for any claims of testing in another engine.
- Keep query outputs deterministically ordered, and avoid redefining business rules silently.
- Open a pull request explaining the learning outcome, changed files, test results and any limitations.
- Contributions should be your original work or appropriately licensed and attributed.

Original contributions are accepted under the MIT license. Preserve third-party notices where required.
